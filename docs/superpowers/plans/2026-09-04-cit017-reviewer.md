# CIT.017 Reviewer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a responsive, browser-only CIT.017 reviewer with source-faithful lessons, scenario tests, progress persistence, an interactive McCumber Cube, and a compact focus timer.

**Architecture:** Use a static React and TypeScript application with route-level Home, Subject, Study, and Test screens. Keep course content in typed modules, behavior in small pure helpers/hooks, and browser persistence behind a versioned adapter so the interface can stay simple and later subjects can be added without changing the CIT.017 feature internals.

**Tech Stack:** React, TypeScript, Vite, React Router, Vitest, Testing Library, Playwright, CSS, localStorage

**Spec:** `docs/superpowers/specs/2026-09-04-cit017-reviewer-design.md`

## Global Constraints

- The three supplied PDFs and the supplied 12-category threat table are authoritative.
- The only externally sourced course addition is the McCumber Cube.
- Use browser-only persistence with no account, backend, cloud sync, or collaboration.
- Keep the experience fast, calm, readable, responsive, keyboard accessible, and respectful of reduced motion.
- Use a crisp white and deep navy interface with a bright electric-lime accent; avoid gradients, mascot art, fake statistics, card overload, and excessive gamification.
- Use test-first development for every behavior and watch each new test fail for the intended reason before implementation.
- Do not add external image assets; render the McCumber Cube and all interface visuals with accessible HTML/CSS and the selected icon library.
